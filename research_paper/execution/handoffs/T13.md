## Acceptance and limitations

The R2-frozen Schur detector is implemented and checked against both an
independent official synthetic example and FAST-LIO's current information
export. The sidecar does not change pose results in the paired smoke.

This remains a detector-only adaptation on shared FAST-LIO correspondences.
It does not reproduce DCReg's physical-axis alignment, PCG preconditioner,
registration pipeline or benchmark results. The pseudoinverse path for
singular blocks is an explicit adaptation; the inspected official C++ code
requires invertible LU blocks. The integration run uses the T12 feasibility
route, not the formal x=-6 m route. No threshold was fit; no held-out inputs
were generated or screened; no recovery result is claimed.
