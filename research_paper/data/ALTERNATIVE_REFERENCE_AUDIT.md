# Alternative reference audit for the recovery study

24 September 2026. This is a **metadata screen**, not acceptance of a new dataset or a reason to download its full bag. A usable real-data recovery sequence needs LiDAR and IMU, a scene-defined weak-to-rich transition, and continuous independently measured 6-DoF reference through enough of both sides to evaluate the frozen 1 s and 3 s windows. A quaternion field containing zeros is not measured orientation. Reference produced by aligning the tested LiDAR to a map is useful for qualified development but not an independent final accuracy check.

| Candidate | Primary-source evidence | Decision before downloading |
| --- | --- | --- |
| Hilti-Oxford Exp18 (already downloaded) | The [event audit](HILTI_EXP18_EVENT.md) supports a scene-defined exit, but the [T07 pilot](../evidence/HILTI_EXP18_T07_PILOT.md) found 13/56 matched post-exit 1 s windows and 0/56 3 s windows with valid reference. The dense reference partly uses LiDAR map registration. | Retain as development software/scene pilot only; not sole quantitative recovery evidence. |
| M2DGR hall / door | The [official release](https://github.com/SJTU-ViSYS/M2DGR) describes Leica-tracker reference for these scenes. The actual [hall_03 reference](https://raw.githubusercontent.com/SJTU-ViSYS/M2DGR/main/hall_03.txt) has position columns followed by `0 0 0 0`, not a valid measured quaternion. The door reference file and its coverage have not yet been inspected. | Do not spend 10–35 GB on a door bag on the assumption that Leica supplies 6-DoF. Inspect that sequence's released reference first; position-only cannot test rotational recovery. |
| ENWIDE | The [ETH Zürich release](https://projects.asl.ethz.ch/datasets/enwide/) explicitly records ground-truth **position** with a Leica total station and includes degenerate tunnel sequences. | Strong geometry, but not a full-rotation reference for the current outcome contract. |
| INSANE UAV transitions | The [university release](https://www.aau.at/en/smart-systems-technologies/control-of-networked-systems/datasets/insane-dataset/) and [paper](https://journals.sagepub.com/doi/10.1177/02783649241227245) document continuous cross-domain reference and IMUs, but the listed sensor suite is cameras/IMUs/GNSS/UWB rather than a LiDAR suitable for the LiDAR-only estimator. | Reference quality alone is insufficient; do not download for this question without verifying an actual LiDAR stream. |
| JEPLO | The [authors' release](https://huggingface.co/datasets/ASIG-Lab/JEPLO-Dataset) lists Livox Mid360, its IMU, five indoor and three mixed sequences, and 6-DoF LiDAR-frame trajectory files. Its [paper](https://arxiv.org/html/2609.15770) specifically establishes independent motion-capture truth inside a 10 m × 4 m room; it does **not** establish independent truth outside that room. Read-only checks of the [published reference files](https://huggingface.co/datasets/ASIG-Lab/JEPLO-Dataset/tree/main/gt) found that Outdoor1 covers a 692.9 s bag but has a 584.2 s reference gap, and Outdoor2 has a 537.2 s reference gap. The Long_Stairs reference spans 248.9 s but its position ranges are only 4.0 × 3.0 × 0.065 m; its provenance outside the capture room is unverified. Total collection is about 9.85 GB. | Reject Outdoor1/2 as continuous transition truth. Do not download a bag until the mixed-sequence truth method and usable transition coverage are demonstrated. Indoor mocap data may remain an independent control, not the required weak-to-rich exit. |
| TIERS | The [official dataset](https://github.com/TIERS/tiers-lidars-dataset) has independently tracked indoor motion-capture sequences; its corridor sequences' published reference method and transition coverage require sequence-specific verification. | Possible independent indoor control, not yet an accepted weak-to-rich exit with continuous truth. |
| HK-MEMS urban tunnels | The [authors' release](https://github.com/RuanJY/HK_MEMS_Dataset#ground-truth) describes tunnel references derived from bus-route data and smoothed barometric altitude; some handheld/robot sequences have RTK position or start-to-end drift only. | Valuable degeneracy challenge, but its released tunnel reference is not a continuous independently measured 6-DoF trajectory for this study. |

The screening criterion is intentionally strict because the [execution plan](../AGENT_EXECUTION_PLAN.md) requires both local translation and rotation recovery and an auditable reference. The immediate next check is small metadata/reference files from other candidates, not another multi-gigabyte bag. If no public sequence meets all criteria, R1 must record a scope revision: use controlled simulation for the primary causal test and present real recordings only as qualified observational checks. That would be a different, narrower claim, not a pass of the original real-data gate.
